## Problem Statement

<div class="header"><div class="title">E. Memory Cell Interception</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>There are two threads, $$$\texttt{A}$$$ and $$$\texttt{B}$$$, and one shared memory cell. Initially, the memory cell contains $$$0$$$.</p><p>Thread $$$\texttt{A}$$$ has a fixed command sequence $$$s$$$ of length $$$n$$$, and thread $$$\texttt{B}$$$ has a fixed command sequence $$$t$$$ of length $$$m$$$. Each command is either $$$\texttt{READ}$$$, denoted by $$$\texttt{R}$$$, or $$$\texttt{WRITE}$$$, denoted by $$$\texttt{W}$$$.</p><p>The commands of each thread must be executed in their original order. However, commands from the two threads may be interleaved arbitrarily. In other words, the actual execution is a global sequence of $$$n+m$$$ commands obtained by merging $$$s$$$ and $$$t$$$ while preserving the order of commands inside each string.</p><p>For example, suppose $$$s=$$$ $$$\texttt{RWW}$$$ and $$$t=$$$ $$$\texttt{WR}$$$.</p><ul> <li> The sequence $$$ s_1,t_1,s_2,t_2,s_3 $$$ is a valid interleaving. The corresponding global command sequence is $$$\texttt{RWWRW}$$$.<p> </p></li><li> The sequence $$$ s_2,t_1,s_1,t_2,s_3 $$$ is not a valid interleaving, because the commands of $$$s$$$ are not executed in their original order.<p> </p></li><li> The sequence $$$ s_1,t_1,s_2,t_2 $$$ is not a valid interleaving, because it does not execute all commands. </li></ul><p>The global execution has timestamps. Before any command is executed, the timestamp is $$$0$$$. The command executed at position $$$i$$$ in the global sequence has timestamp $$$i$$$.</p><ul> <li> When a $$$\texttt{WRITE}$$$ command is executed at timestamp $$$i$$$, it writes the value $$$i$$$ into the shared memory cell.</li><li> When a $$$\texttt{READ}$$$ command is executed, it reads the current timestamp value stored in the shared memory cell. </li></ul><p>For every $$$\texttt{READ}$$$ command appearing in either $$$s$$$ or $$$t$$$, determine how many distinct values it can read over all valid interleavings of the two command sequences.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows.</p><p>The first line of each test case contains two integers $$$n$$$ and $$$m$$$ ($$$1 \le n,m \le 2 \cdot 10^5$$$) — the lengths of the command sequences of threads $$$\texttt{A}$$$ and $$$\texttt{B}$$$, respectively.</p><p>The second line contains a string $$$s$$$ of length $$$n$$$ — the command sequence of thread $$$\texttt{A}$$$.</p><p>The third line contains a string $$$t$$$ of length $$$m$$$ — the command sequence of thread $$$\texttt{B}$$$.</p><p>Each character of $$$s$$$ and $$$t$$$ is either $$$\texttt{R}$$$ or $$$\texttt{W}$$$. Each of the strings $$$s$$$ and $$$t$$$ contains at least one character $$$\texttt{R}$$$.</p><p>It is guaranteed that the sum of all $$$n$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$, and the sum of all $$$m$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print two lines.</p><p>The first line contains a sequence of integers, representing the answer for each $$$\texttt{READ}$$$ instruction appearing in $$$s$$$ in order. The length of the sequence must equal the number of letters $$$\texttt{R}$$$ in $$$s$$$.</p><p>The second line contains a sequence of integers, representing the answer for each $$$\texttt{READ}$$$ instruction appearing in $$$t$$$ in order. The length of the sequence must equal the number of letters $$$\texttt{R}$$$ in $$$t$$$.</p></div><div class="sample-tests"><div class="section-title">Example</div><div class="sample-test"><div class="input"><div class="title">Input<div title="Copy" data-clipboard-target="#id00008797835233153473" id="id004784260326765879" class="input-output-copier">Copy</div></div><pre data-content="3
