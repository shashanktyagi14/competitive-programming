Each node $$$i$$$ ($$$1 \le i \le n$$$) has a binary state, initially equal to $$$x_i$$$ ($$$x_i \in \{\texttt{0},\texttt{1}\}$$$) and a target binary state $$$y_i$$$ ($$$y_i \in \{\texttt{0},\texttt{1}\}$$$) associated with it.</p><p>You wish to make the state of every node equal to its target state. If it has no children, then the pulse disappears. Every pulse sent to a child follows the same propagation rules. </li></ul><p>Determine whether it is possible to make the state of every node equal to its target state.
