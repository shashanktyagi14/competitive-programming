Since Sofia is a great expert on robots, Fran will need your help to win the championship.</p><p> A match of the tournament takes place on an $$$n \times n$$$ board. The rows are numbered from <span class="tex-font-style-bf">bottom to top</span> and the columns from left to right, so $$$(1, 1)$$$ is the bottom-left corner and $$$(n, n)$$$ is the top-right corner. The opponent's robot is hidden at some unknown cell $$$(i, j)$$$ and moves once every second, but you do not see it.</p><p>At the beginning of each second $$$s$$$, before the robot moves, you must choose an integer $$$v$$$ with $$$2 \le v \le 2n$$$ and shoot a laser along the diagonal</p><p>$$$$$$\{\, (r, c) \mid r + c = v \,\}.$$$$$$ The laser touches the robot if the robot is currently on a cell of that diagonal, in which case you win immediately. Otherwise, after your shot, suppose the robot is currently at $$$(r, c)$$$, the robot moves to one of the following cells, provided the move stays inside the board: </p><ul> <li> up: $$$(r + 1, c)$$$; </li><li> right: $$$(r, c + 1)$$$; </li><li> down-left: $$$(r - 1, c - 1)$$$. </li></ul> <center> <img class="tex-graphics" src="https://espresso.codeforces.com/76c8fb5da81a03caa0f7e955b4dd790574238278.png" style="max-width: 100.0%;max-height: 100.0%;" width="378px">  <span class="tex-font-style-it">The robot is at cell $$$(3,2)$$$ (its diagonal is $$$r+c=5$$$). The green laser is the diagonal $$$v=7$$$, which does not touch the robot.</span> </center><p>The robot is adversarial: it may start on any cell, and it may choose any valid sequence of moves.
